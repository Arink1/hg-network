The fastest way to kill a Rust server is an admin with a base. So on HGRusty, nobody with admin or moderator access plays on the server. Not on an alt, not on a friend's account, not "just to test".

## What admins can do

- Respond to cheat reports and review combat logs
- Check group limits with TC auth lists and base logs
- Handle tickets, bans and appeals
- Run wipes and updates

## What admins cannot do

- Own or be authed on any tool cupboard
- Spawn items for anyone outside a documented server issue
- Teleport to players without an open ticket

Every admin action is logged and the log is reviewed weekly by a different admin. If you think an admin broke this policy, open a ticket in Discord and include the time. We take those seriously.
